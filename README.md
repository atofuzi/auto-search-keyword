# 前提などまったくなくても分かる！ キーワード調査ツールの使い方

このツールは、Yahoo!検索を使って「ライバルのいない（少ない）キーワード」を自動で見つけるためのアプリです。
エンジニアではない方でも使えるように、ゼロからのセットアップ手順をまとめました。

1.  [Node.js公式サイト](https://nodejs.org/en) にアクセスします。
2.  **"LTS"** と書かれた方のボタン（推奨版）をクリックしてダウンロードします。
3.  ダウンロードしたファイル（`.pkg`）を開き、画面の指示に従ってインストールします。
4.  インストール完了後、ターミナルを開いて `node -v` と入力し、バージョン番号が出れば成功です！

---

### 方法B: Homebrew & NVM を使ったインストール (エンジニア向け)

Homebrew (Macのパッケージ管理ツール) を使って環境を作る、最も一般的な方法です。

1.  **Homebrew のインストール**
    まだ入っていない場合は、[公式サイト](https://brew.sh/ja/) の手順に従ってインストールしてください。
    ※この過程で必要な開発ツール (Xcode Command Line Tools) も自動的にセットアップされるため、個別のインストールは不要です。

2.  **Git のインストール**
    ```bash
    brew install git
    ```

3.  **NVM (Node Version Manager) のインストール**
    以下のコマンドを実行します。
    ```bash
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
    ```
    *   インストール後、画面の指示に従ってパス設定（`export NVM_DIR...`）を `.zshrc` や `.bash_profile` に記述し、`source` コマンドで読み込んでください。

4.  **Node.js のインストール**
    ```bash
    nvm install --lts
    ```

**※トラブルシューティング**
もし `command not found: nvm` と出る場合、設定ファイルが読み込めていません。以下を実行してください。
```bash
source ~/.nvm/nvm.sh
```
（毎回このコマンドを打たなくて済むようにするには、`.zshrc` への追記が必要です。詳細はネットで「nvm zsh 設定」などで検索するか、方法Aをご検討ください）

## ステップ2: アプリの準備をする

この説明書があるフォルダ（アプリの場所）で作業します。

1.  ターミナルで、このアプリのフォルダに移動します。
    （Finderでこのフォルダを開き、ターミナルに `cd ` （シーディー・スペース）と打ってから、フォルダをドラッグ＆ドロップすると簡単です）
    ```bash
    cd /path/to/auto-search-keyword  <-- ここは実際の場所になります
    ```
2.  以下のコマンドを実行して、必要な部品をダウンロードします。
    ```bash
    npm install
    ```
    （※自動的に `client` フォルダの準備やPlaywrightのインストールも行われます。少し時間がかかります）

## ステップ3: アプリを起動する

1.  以下のコマンドを入力します。
    ```bash
    npm run dev
    ```
2.  画面に `Local: http://localhost:5173/` のような文字が出れば起動成功です。
3.  Google Chromeなどのブラウザを開き、アドレスバーに以下を入力して移動します。
    `http://localhost:5173`

## ステップ4: ツールの使い方

画面が表示されたら、以下のように操作します。

1.  **Collected Suggestions (取得した関連キーワード)**:
    *   調査を開始すると、自動的に「虫眼鏡キーワード」が収集され、画面中央に一覧表示されます。
    *   「リストを表示 / リストを隠す」ボタンで表示を切り替えられます。
    *   ここに出るキーワードを中心に調査が進みます。
2.  **狙っているワード (Base Keyword)**: 調べたいメインのキーワードを入力します（例: `ミラノオリンピック`）。
3.  **オプション (Custom Check Words)**: （基本は空欄でOK）
    *   ライバル記事タイトルに含まれているかチェックしたいキーワードを入力します。
    *   例）ミラノオリンピック → ミラノも対象にしたい場合は「ミラノ」と記載。
4.  **ライバルレス判定基準 (Rival Threshold)**:
    *   「すべてのキーワードがタイトルに含まれる記事が [ X ] 記事以内」の設定です。デフォルトは `3` です。
    *   ここに設定した数字以下しかヒットしない場合、「ライバル不在」と判定されます。
5.  **Verification Mode**: （開発者向け）
    *   `.env.example` をコピーして `.env` ファイルを作成し (`cp .env.example .env`)、`VERIFICATION_MODE=true` と記述することで、テスト用に検索範囲を限定（あ行〜か行のみ）して素早く動かせます。
    *   または起動時に `VERIFICATION_MODE=true npm run dev` としても有効になります。
6.  **実行 (Start)**: ボタンを押すと調査が始まります。
    *   画面下部のログに進行状況が表示されます。
    *   「Found Rival-less」と出たら、お宝キーワード発見です！

### 結果の見方
*   結果カードをクリックすると、詳細画面が開きます。
*   **「1. Copy Prompt for Gemini」** を押すと、Gemini（AI）用の指示文がコピーされます。
*   **「2. Open Gemini」** を押してAIを開き、貼り付けるだけで、記事の構成案を作ってもらえます。

### ⚠️ 重要な注意点（やりすぎ注意）
このツールはあなたのPCの回線を使って検索します。短時間に大量のアクセスを行うと、Yahoo!から一時的にアクセス制限（BAN）を受ける可能性があります。

*   **1回の実行時間**: 1つの「狙っているワード」に対する調査は、通常 **10分〜20分程度** で終わります。これは安全圏です。
*   **連続実行**: 続けて別のワードを調査する場合は、**5分ほど休憩** させてから実行することをお勧めします。
*   **スリープモード**: 実行中にPCが画面OFFになると処理が止まってしまいます。
    *   **Macの方**: 以下のコマンドで起動すると、実行中だけスリープを無効化できます（おすすめです）。
        ```bash
        npm run dev:awake
        ```
    *   その他の方: 実行中はスリープしないよう設定してください。

※もし検索できなくなった場合は、ルーターを再起動してIPアドレスを変えるか、半日ほど時間を空けてください。
