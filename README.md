# 前提などまったくなくても分かる！ キーワード調査ツールの使い方

このツールは、Yahoo!検索を使って「ライバルのいない（少ない）キーワード」を自動で見つけるためのアプリです。
エンジニアではない方でも使えるように、ゼロからのセットアップ手順をまとめました。

## ステップ1: 必要な道具（Node.js）を入れる

このアプリを動かすには **Node.js（ノード・ジェイエス）** というソフトが必要です。
以下の手順でインストールしてください。

### Macをお使いの方
1.  **ターミナル** を開きます（「アプリケーション」→「ユーティリティ」→「ターミナル」、またはSpotlight検索で「terminal」と入力）。
2.  以下のコマンドをコピーして、ターミナルに貼り付け、エンターキーを押します。
    （これは `nvm` という管理ツールを入れるコマンドです）
    ```bash
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
    ```
3.  インストールが終わったら、一度ターミナルを終了して、もう一度開き直してください。
4.  次に、以下のコマンドを入力してエンターキーを押します（Node.js本体を入れます）。
    ```bash
    nvm install --lts
    ```
5.  これで準備完了です！

※ もし `git` がないと言われた場合、Macなら「インストールしますか？」という画面が出ることがあります。その場合は「インストール」を押して進めてください。

---

## ステップ2: アプリの準備をする

この説明書があるフォルダ（アプリの場所）で作業します。

1.  ターミナルで、このアプリのフォルダに移動します。
    （Finderでこのフォルダを開き、ターミナルに `cd ` （シーディー・スペース）と打ってから、フォルダをドラッグ＆ドロップすると簡単です）
    ```bash
    cd /path/to/auto-search-keyword  <-- ここは実際の場所になります
    ```
2.  以下のコマンドを実行して、必要な部品をダウンロードします。
    ```bash
    npm install
    ```
    （少し時間がかかります。文字がたくさん流れて止まればOKです）

---

## ステップ3: アプリを起動する

1.  以下のコマンドを入力します。
    ```bash
    npm run dev
    ```
2.  画面に `Local: http://localhost:5173/` のような文字が出れば起動成功です。
3.  Google Chromeなどのブラウザを開き、アドレスバーに以下を入力して移動します。
    `http://localhost:5173`

---

## ステップ4: ツールの使い方

画面が表示されたら、以下のように操作します。

1.  **Collected Suggestions**:
    *   調査を開始すると、自動的に「虫眼鏡キーワード」が収集され、画面中央に一覧表示されます。
    *   「Show/Hide List」ボタンで表示を切り替えられます。
    *   ここに出るキーワードを中心に調査が進みます。
2.  **Base Keyword**: 調べたいメインのキーワードを入力します（例: `ミラノオリンピック`）。
3.  **Custom Check Words**: （基本は空欄でOK）特定の単語が含まれているか特にチェックしたい場合に入力します。
4.  **Rival Threshold**: 「ライバルが何件以下ならチャンスとみなすか」の設定です。デフォルトは `3` です。
    *   ここに設定した数字以下しかヒットしない場合、「ライバル不在」と判定されます。
5.  **Verification Mode**: （開発者向け）
    *   `.env.example` をコピーして `.env` ファイルを作成し (`cp .env.example .env`)、`VERIFICATION_MODE=true` と記述することで、テスト用に検索範囲を限定（あ行〜か行のみ）して素早く動かせます。
    *   または起動時に `VERIFICATION_MODE=true npm run dev` としても有効になります。
6.  **START SCRAPING**: ボタンを押すと調査が始まります。
    *   画面下部のログに進行状況が表示されます。
    *   「Found Rival-less」と出たら、お宝キーワード発見です！

### 結果の見方
*   結果カードをクリックすると、詳細画面が開きます。
*   **「1. Copy Prompt for Gemini」** を押すと、Gemini（AI）用の指示文がコピーされます。
*   **「2. Open Gemini」** を押してAIを開き、貼り付けるだけで、記事の構成案を作ってもらえます。

### 終了するとき
ターミナルで `Ctrl` キーを押しながら `C` キーを押すと終了します。
