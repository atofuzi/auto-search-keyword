# キーワード調査ツール 使い方マニュアル

Yahoo!検索の虫眼鏡サジェストを自動収集し、「ライバル記事が少ないキーワード（ライバルレスキーワード）」を見つけるためのツールです。

## 1. セットアップ

### 必要なもの

- macOS（推奨）または Windows
- Node.js v18 以上（[公式サイト](https://nodejs.org/en) の **LTS** 版をインストール）

### インストール手順

```bash
# 1. リポジトリをクローン（またはフォルダをダウンロード）
git clone <リポジトリURL>
cd auto-search-keyword

# 2. 依存パッケージをインストール（Playwright も自動でインストールされます）
npm install

# 3. 環境変数ファイルを作成
cp .env.example .env
```

> **Note**  
> `npm install` 実行時に `client` フォルダの依存関係とPlaywrightのブラウザも自動でインストールされます。数分かかる場合があります。

## 2. 起動方法

### 通常起動

```bash
npm run dev
```

ターミナルに `Local: http://localhost:5173` と表示されたら起動成功です。  
ブラウザで `http://localhost:5173` を開いてください。

### スリープ防止起動（長時間実行時・推奨）

```bash
npm run dev:awake
```

実行中にMacがスリープすると処理が止まります。長時間の調査には `dev:awake` を使ってください（`caffeinate` コマンドを利用しています）。

## 3. 画面の見方と操作手順

### Step 1: キーワードを入力する

| 項目 | 説明 | 例 |
|------|------|-----|
| **狙っているワード（Base Keyword）** | 調べたいメインキーワード | `ミラノオリンピック` |
| **Custom Check Words** | ライバル記事タイトルに含まれているかチェックしたい追加ワード（空欄でもOK） | `ミラノ` |
| **ライバルレス判定基準（Rival Threshold）** | タイトルに全ワードが含まれる記事が何件以下ならライバル不在とするか | `3`（デフォルト） |

### Step 2: 調査を開始する

**「Start」ボタン** を押すと2段階で調査が進みます。

#### フェーズ1: サジェスト収集

Yahoo!検索の虫眼鏡サジェストを「あ行〜ん」で自動収集します。  
収集されたキーワードは画面中央の **「Collected Suggestions」** に一覧表示されます。

- 「リストを表示 / リストを隠す」で表示を切り替えられます
- 収集には数分かかります（通常50〜100件以上）

#### フェーズ2: ライバル分析

収集したキーワードそれぞれについて、Yahoo!検索の上位10件のタイトルをチェックし、ライバル記事の数を計測します。

画面下部のログに **「Found Rival-less: ○○」** と表示されたら、ライバル不在キーワード発見です！

### Step 3: 途中で止めたい場合

**「Stop」ボタン** を押すと、現在の処理が安全に停止します。それまでの結果は保存されています。

## 4. 結果の活用方法

### 結果カード

ライバルレスと判定されたキーワードはカードとして画面に表示されます。カードをクリックすると詳細画面が開きます。

### Gemini（AI）で記事構成を作成する

1. **「1. Copy Prompt for Gemini」** ボタンを押す → AIへの指示文がクリップボードにコピーされます
2. **「2. Open Gemini」** ボタンを押す → Gemini が開きます
3. コピーした内容を貼り付けて送信すると、そのキーワードに合わせた記事の構成案を生成してくれます

### CSV ダウンロード

結果は自動的に `rival_less_keywords_<キーワード>_<タイムスタンプ>.csv` として保存されます。  
スプレッドシートにインポートして管理することができます。

## 5. 環境設定（上級者向け）

`.env` ファイルを編集することで動作をカスタマイズできます。

```env
# 検索範囲を「あ行〜か行」に限定して高速テストを行うモード
VERIFICATION_MODE=false

# ログレベル: debug | info | warn | error
# debug: ソケット通信の詳細ログも出力
# info: 通常使用（デフォルト）
LOG_LEVEL=info
```

起動時のオプションとして渡すこともできます。

```bash
VERIFICATION_MODE=true npm run dev
```

## 6. 注意事項・トラブルシューティング

### ⚠️ やりすぎ注意（BAN防止）

このツールはあなたのPCの回線を使って Yahoo! へアクセスします。短時間に大量にアクセスすると、一時的にアクセス制限を受けることがあります。

| 項目 | 目安 |
|------|------|
| 1ワードあたりの調査時間 | 10〜20分程度（安全圏） |
| 連続して別ワードを調べる場合 | 5分ほど休憩してから実行 |

### 検索できなくなった場合

- **ルーターを再起動** してIPアドレスをリセットする
- **半日〜1日ほど時間を空ける**

### キャッシュについて

一度収集したサジェスト結果は `cache_<キーワード>.json` として保存されます。  
同じキーワードを再実行した場合、キャッシュが使われるため処理がスキップされ高速に動作します。  
キャッシュをクリアしたい場合は該当の `cache_*.json` ファイルを削除してください。

### よくあるエラー

| エラー | 対処法 |
|--------|--------|
| `command not found: node` | Node.js がインストールされていない → [公式サイト](https://nodejs.org/en) からインストール |
| ブラウザが起動しない | `npm install` を再実行する（Playwright のインストール漏れの可能性） |
| 画面が真っ白 | ターミナルにエラーが出ていないか確認。`npm run dev` を再起動 |
| 結果が0件になる | アクセス制限の可能性。ルーター再起動か時間を空けてリトライ |
